# Algorithms Core Notes

Algorithms Core Notes is an interactive React revision guide for common algorithms, problem-solving patterns, complexity, and practical JavaScript implementations.

![Algorithms Core Notes preview](screenshot.png)

## Topics

- Foundation Layer
- Searching and Sorting
- Recursion Patterns
- Sliding Window
- Stack and Queue
- Greedy Algorithms
- Dynamic Programming
- Graph Algorithms

## Features

- Bookmarkable topic routes under `/algorithms-core-notes/`
- Lazy-loaded pages with a loading state
- Responsive desktop sidebar and mobile topic navigation
- Fixed header with scroll hide/show behavior
- Scroll-to-top navigation and practical complexity notes
- Accessible controls and keyboard focus states

## Tech Stack

React, Vite, React Router, JavaScript, React Icons, and CSS Modules.

## Getting Started

```bash
npm install
npm run dev
```

Production checks:

```bash
npm run lint
npm run build
```
