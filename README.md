# Algorithms Core Notes

Algorithms Core Notes is an interactive React revision guide for understanding common algorithms, problem-solving patterns, complexity, and practical JavaScript implementations.

## Topics

- Foundation Layer
- Searching and Sorting
- Recursion Patterns
- Sliding Window
- Stack and Queue
- Greedy Algorithms
- Dynamic Programming
- Graph Algorithms

## Features

- Clean route for every topic
- Lazy-loaded pages with a loading state
- Responsive desktop sidebar and mobile topic navigation
- Scroll-to-top navigation and fixed header with scroll behavior
- Practical explanations, examples, and complexity notes
- Accessible controls and keyboard focus states

## Tech Stack

React, Vite, React Router, JavaScript, React Icons, and CSS styling.

## Getting Started

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run lint
npm run build
```
